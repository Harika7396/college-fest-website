# Campus Vibes — College Fest Website

A responsive college festival website built with **HTML, CSS and vanilla JavaScript**.

## Features
- Responsive landing page and mobile navigation
- Technical, cultural, workshop and fun event cards
- Category filters for event cards
- Three-day interactive agenda
- Event coordinator cards
- Participation rules and guidelines
- Registration form with browser validation and demo confirmation
- Accessible labels, semantic sections and responsive styling

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser. For a smoother development experience, use VS Code's Live Server extension.

## Important demo notes
- Dates, times, event fees and coordinator contacts are sample details. Replace them with your actual college fest information.
- The registration form is front-end only. It does not transmit or store submissions. Connect a backend or form service before using it for real registrations.
- Google Fonts requires an internet connection; system sans-serif fonts are used as fallbacks.
